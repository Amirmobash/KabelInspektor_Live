# Featured Projects

## Receiver_ESP8266 — Laser Distance Receiver

An ESP8266 / NodeMCU project designed to receive measurement data from a laser distance device and display the measured distance on a **1.3-inch I2C OLED display**.

The project demonstrates how wireless communication, embedded hardware and measurement systems can be combined in a practical application.

**Technologies:**

ESP8266 · NodeMCU · C++ · OLED · HTTP · JSON · IoT · Embedded Systems

**Project:**

https://github.com/Amirmobash/Receiver_ESP8266

---

## RFID Communication with RC522 and Raspberry Pi

A Raspberry Pi project for controlling and communicating with an **RFID RC522 module using SPI**.

The project can be used as a practical learning example for RFID identification, embedded electronics and access-control concepts.

**Technologies:**

Raspberry Pi · Python · RFID RC522 · SPI · Embedded Systems · Electronics

**Project:**

https://github.com/Amirmobash/RFID-Kommunikation
